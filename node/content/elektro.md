Durch das Programm vorgegebene elektrotechnische Aufgaben lösen.
Wobei man die Parameter der Aufgabe selbst bestimmen kann.
Die Aufgabe wird aus den vielen Beispielen der Fachliteratur entnommen.

Das Ziel:
Die Ausgabe erfolgt in einer Tabelle und kann über ein View durch Diagramme, Schaltbilder
visualisiert werden.Will man ein Datenreihe oder eine Berechnungsreihe bilden, kann diese in einer Datenbank gespeichert werden. Über eine Schnittstelle können Daten über einen Datenlogger abgefragt werden. Dabei können 
unterschiedliche Protokolle, welche in der Industie üblich sind, verwendet werden.
