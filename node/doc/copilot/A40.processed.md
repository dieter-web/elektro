## Kurvendiskussion  

### 1. U2/U (Ausgangsspannungsverhältnis)  
- Mit wachsendem R2 steigt U2/U asymptotisch gegen den Wert des offenen Spannungsteilers (R2/(R1+R2)).  
- Für kleine R2 dominiert R1, U2/U ist niedrig. Mit größerem R2 nähert sich U2/U dem Verhältnis R2/(R1+R2).  
- Höhere Ra-Werte verlangsamen den Anstieg: Mehr Last zieht die Kurve nach unten.

### 2. Ia/Iamax (Laststromverhältnis)  
- Ia/Iamax = Ia / (U2/Ra).  
- Für kleine R2 ist U2 niedrig, Iamax klein → Ia/Iamax groß. Mit steigendem R2 wächst U2, Iamax steigt, Ia/Iamax fällt.  
- Bei größerem Ra sind Iamax kleiner (höherer Widerstand) → Ia/Iamax für alle R2-Werte größer.

// Datei: calculate.js
// Installieren: npm install mathjs
const math = require('mathjs');
const fs = require('fs');

// Parameter
const U = 100;         // Versorgungsspannung in V
const R1 = 20;         // R1 in Ω
const Ra_values = [2, 7, 15, 30];      // zu untersuchende Ra-Werte in Ω
const R2_steps = math.range(1, 101, 1).toArray();  // R2 von 1 bis 100 Ω

// Hilfsfunktion: berechne U2/U und Ia/Iamax
function calcCurve(R2, Ra) {
  // Spannungsteilerglied:
  // R_eq = (R2 * Ra) / (R2 + Ra)
  const R_eq = math.divide(math.multiply(R2, Ra), math.add(R2, Ra));
  // Ausgangsspannung mit Last
  const U2_loaded = math.multiply(U, math.divide(R_eq, math.add(R1, R_eq)));
  // Leerlauf-Ausgangsspannung
  const U2_open = math.multiply(U, math.divide(R2, math.add(R1, R2)));
  // Ströme
  const Ia = math.divide(U2_loaded, Ra);
  const Iamax = math.divide(U2_open, Ra);
  return {
    R2,
    U2_rel: math.divide(U2_loaded, U),      // U2/U
    I_rel: math.divide(Ia, Iamax)           // Ia/Iamax
  };
}

// Datenstruktur
const data = Ra_values.map(Ra => ({
  Ra,
  curve: R2_steps.map(R2 => calcCurve(R2, Ra))
}));

// als JSON speichern
fs.writeFileSync('data.json', JSON.stringify(data, null, 2));
console.log('Daten in data.json gespeichert.');

Um den Belastungswiderstand $ R_a $ zu berechnen, brauchst du typischerweise folgende Größen:

- Gesamtspannung $ U $
- Spannungsteilerwiderstände $ R_1 $ und $ R_2 $
- Strom durch den Belastungswiderstand $ I_a $

### Formel zur Berechnung von $ R_a $

Wenn du einen Spannungsteiler mit Last hast, ergibt sich die Ausgangsspannung $ U_2 $ über den Ersatzwiderstand von $ R_2 $ und $ R_a $:

$$
U_2 = U \cdot \frac{R_2 \parallel R_a}{R_1 + (R_2 \parallel R_a)}
\quad\text{mit}\quad
R_2 \parallel R_a = \frac{R_2 \cdot R_a}{R_2 + R_a}
$$

Da $ U_2 = I_a \cdot R_a $, kannst du einsetzen und nach $ R_a $ auflösen:

$$
I_a \cdot R_a = U \cdot \frac{R_2 \cdot R_a}{R_2 + R_a + R_1}
$$

Diese Gleichung kannst du umstellen:

$$
I_a (R_2 + R_a + R_1) = U \cdot \frac{R_2}{R_a}
\quad\Rightarrow\quad
I_a R_a^2 + I_a(R_1 + R_2)R_a - U R_2 = 0
$$

Das ist eine quadratische Gleichung in $ R_a $, die du mit der Mitternachtsformel lösen kannst:

$$
R_a = \frac{-I_a(R_1 + R_2) \pm \sqrt{[I_a(R_1 + R_2)]^2 + 4 I_a U R_2}}{2 I_a}
$$

---

### Beispiel:  
Gegeben:  
- $ U = 100\,\text{V} $  
- $ R_1 = 20\,\Omega $, $ R_2 = 15\,\Omega $  
- $ I_a = 3\,\text{A} $

Einsetzen:

$$
R_a = \frac{-3(20 + 15) \pm \sqrt{[3(35)]^2 + 4 \cdot 3 \cdot 100 \cdot 15}}{2 \cdot 3}
= \frac{-105 \pm \sqrt{11025 + 18000}}{6}
= \frac{-105 \pm \sqrt{29025}}{6}
= \frac{-105 \pm 170.4}{6}
$$

Nur die positive Lösung ist physikalisch sinnvoll:

$$
R_a = \frac{65.4}{6} \approx 10.9\,\Omega
$$

// Datei: berechneRa.js
// Installation: npm install mathjs
const math = require('mathjs');

// Gegebene Werte
const U = 100;      // Spannung in Volt
const R1 = 20;      // Widerstand R1 in Ohm
const R2 = 15;      // Widerstand R2 in Ohm
const Ia = 3;       // Strom durch Ra in Ampere

// Koeffizienten der quadratischen Gleichung: a·Ra² + b·Ra + c = 0
const a = Ia;
const b = Ia * (R1 + R2);
const c = -U * R2;

// Mitternachtsformel
const discriminant = math.pow(b, 2) - 4 * a * c;
if (discriminant < 0) {
  console.log("Keine reale Lösung für Ra.");
} else {
  const sqrtD = math.sqrt(discriminant);
  const Ra1 = (-b + sqrtD) / (2 * a);
  const Ra2 = (-b - sqrtD) / (2 * a);
  const Ra = Ra1 > 0 ? Ra1 : Ra2;
  console.log(`Berechneter Belastungswiderstand Ra: ${math.round(Ra, 3)} Ω`);
}

## 🧮 Variante 1: numerisch mit `math.solve`

Da `math.js` keine symbolische Gleichungslösung wie CAS-Systeme bietet, nutzen wir die Gleichung:

$$
f(R_a) = I_a \cdot R_a - U \cdot \frac{R_2 \cdot R_a}{R_1(R_2 + R_a) + R_2 \cdot R_a}
$$

Wir suchen die Nullstelle von $ f(R_a) $. Das geht mit `math.evaluate` und einem numerischen Root-Finder wie Newton.

---

## ⚙️ Newton-Verfahren in Node.js

```js
import { create, all } from 'mathjs'
const math = create(all)

const U = 100
const R1 = 20
const R2 = 15
const Ia = 3

// Funktion f(Ra)
function f(Ra) {
  const numerator = U * R2 * Ra
  const denominator = R1 * (R2 + Ra) + R2 * Ra
  return Ia * Ra - numerator / denominator
}

// Ableitung f'(Ra) numerisch
function df(Ra) {
  const h = 1e-6
  return (f(Ra + h) - f(Ra - h)) / (2 * h)
}

// Newton-Verfahren
function newton(start, maxIter = 20, tol = 1e-10) {
  let x = start
  for (let i = 0; i < maxIter; i++) {
    const fx = f(x)
    const dfx = df(x)
    if (Math.abs(fx) < tol) return x
    if (dfx === 0) throw new Error("Ableitung = 0")
    x = x - fx / dfx
  }
  throw new Error("Keine Konvergenz")
}

try {
  const Ra = newton(5) // Startwert nahe der Lösung
  console.log(`Berechneter Ra (Newton): ${math.round(Ra, 6)} Ω`)
} catch (err) {
  console.error("Fehler:", err.message)
}
```
