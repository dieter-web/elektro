### Aufgabe und Annahmen
Gegeben: Spannungsteiler mit Gesamtwiderstand 20 kΩ, Teilwiderstand (unterer) 15 kΩ, angelegte Spannung 220 V. Messgerät: Messbereich 250 V bei Endausschlag; Strom bei Endausschlag 25 mA (innere Widerstand des Messgeräts \(R_m\)).

### Unbelastete Spannung am 15 kΩ
Spannungsteiler: oberer Widerstand \(R_{\text{oben}} = 20\text{k}\Omega - 15\text{k}\Omega = 5\text{k}\Omega\).  
Unbelastete Spannung am unteren Teilwiderstand:
\[
U_{15,\text{unbelastet}} = 220\ \text{V}\cdot\frac{15\text{k}\Omega}{20\text{k}\Omega}=220\cdot\frac{15}{20}=220\cdot0{,}75=165\ \text{V}.
\]

### Messgerät: Innenwiderstand
\[
R_m=\frac{250\ \text{V}}{25\ \text{mA}}=\frac{250}{0{,}025}=10000\ \Omega=10\text{k}\Omega.
\]

### Belastete Spannung am Teilwiderstand (Messgerät angeschlossen)
Der Messkäfig liegt parallel zum 15 kΩ; effektiver unterer Widerstand:
\[
R_{\text{unten}} = \frac{15\text{k}\Omega \cdot 10\text{k}\Omega}{15\text{k}\Omega + 10\text{k}\Omega}
= \frac{150\cdot10^6}{25\cdot10^3}=6000\ \Omega = 6\text{k}\Omega.
\]
Spannung am parallelen Bündel (vom Gesamt 220 V):
\[
U_{\text{gemessen}} = 220\ \text{V}\cdot\frac{6\text{k}\Omega}{5\text{k}\Omega+6\text{k}\Omega}
=220\cdot\frac{6}{11}=220\cdot0{,}545454\ldots=120\ \text{V}.
\]

### Ergebnis (kurz)
- Unbelastete Spannung am 15 kΩ: 165 V.  
- Vom Messgerät angezeigte Spannung (mit Belastung): 120 V.

-### Lösungskonzept
- Berechne mit mathjs (Unit) die unbelastete Spannung am 15 kΩ-Teilwiderstand und den Effekt der Belastung durch das Messgerät (R_m aus Messbereich und Endstrom).  
- Erzeuge eine einfache Visualisierung (SVG) mit d3.js (serverseitig mit jsdom) die den Spannungsteiler, Teilwiderstände und die beiden Spannungen (unbelastet, gemessen) darstellt.

### Vorbereitung (einmalig)
Installiere die benötigten Pakete:
```bash
npm install mathjs d3 jsdom
```

### Node-Skript (math.js Unit + d3.js)
Speichere dieses Skript z.B. als measure-divider.js und führe `node measure-divider.js` aus:

```js
// measure-divider.js
const fs = require('fs');
const { create, all, unit } = require('mathjs');
const d3 = require('d3');
const { JSDOM } = require('jsdom');

const math = create(all);

// Gegebene Werte
const U_in = math.unit(220, 'V');
const R_total = math.unit(20, 'kohm');
const R_bottom = math.unit(15, 'kohm');

// Messgerät: Bereich 250V, Endstrom 25mA
const meas_range = math.unit(250, 'V');
const meas_fullscale_current = math.unit(25, 'mA');

// Hilfsfunktionen für bequemes Vergleichen/Formatieren
const toOhm = x => math.unit(x).toNumber('ohm');
const toVolt = x => math.unit(x).toNumber('V');
const fmt = (val, unitStr) => math.format(math.unit(val, unitStr).toNumber(unitStr), { notation: 'fixed', precision: 6 });

// 1) Unbelastete Spannung am 15kΩ
const U_unloaded = math.multiply(U_in, math.divide(R_bottom, R_total)); // Unit result

// 2) Innenwiderstand des Messgeräts Rm = U_range / I_fs
const Rm = math.divide(meas_range, meas_fullscale_current); // Unit

// 3) Effektiver unterer Widerstand bei Parallelschaltung R_bottom || Rm
function parallel(R1, R2) {
	return math.multiply(math.divide(R1, 1), math.divide(R2, 1))
		? math.divide(math.multiply(R1, R2), math.add(R1, R2))
		: math.divide(math.multiply(R1, R2), math.add(R1, R2));
}
const R_eff_bottom = parallel(R_bottom, Rm);
// 4) Spannung am unteren Bündel bei Belastung
const R_top = math.subtract(R_total, R_bottom);
const U_loaded = math.multiply(U_in, math.divide(R_eff_bottom, math.add(R_top, R_eff_bottom)));

// Konsolenausgabe (klarer numerischer Wert)
console.log('Eingangsspannung Uin:', fmt(U_in.toNumber('V'), 'V'), 'V');
console.log('Unbelastete Spannung am 15kΩ:', `${toVolt(U_unloaded)} V`);
console.log('Innenwiderstand Messgerät Rm:', `${toOhm(Rm)} Ω`);
console.log('Effektiver unterer Widerstand R_eff_bottom:', `${toOhm(R_eff_bottom)} Ω`);
console.log('Gemessene Spannung (mit Belastung):', `${toVolt(U_loaded)} V`);

// --- SVG-Visualisierung mit d3 + jsdom ---
// einfache Balken-Darstellung der Spannungen und Widerstände
const width = 700;
const height = 240;
const margin = { top: 20, right: 20, bottom: 30, left: 120 };

const dom = new JSDOM(`<html><body></body></html>`);
const body = d3.select(dom.window.document).select('body');

const svg = body.append('svg')
	.attr('xmlns', 'http://www.w3.org/2000/svg')
	.attr('width', width)
	.attr('height', height);

// Werte für die Visualisierung
const values = [
	{ name: 'R_top (5kΩ)', value: toOhm(R_top) / 1000, unit: 'kΩ' },
	{ name: 'R_bottom (15kΩ)', value: toOhm(R_bottom) / 1000, unit: 'kΩ' },
	{ name: 'R_m (Messgerät)', value: toOhm(Rm) / 1000, unit: 'kΩ' },
	{ name: 'U_unloaded', value: toVolt(U_unloaded), unit: 'V' },
	{ name: 'U_loaded', value: toVolt(U_loaded), unit: 'V' }
];

// Skalierung: zwei Bereiche (Widerstände in kΩ links, Spannungen in V rechts)
const maxKohm = d3.max(values.filter(d => d.unit === 'kΩ'), d => d.value) || 1;
const maxVolt = d3.max(values.filter(d => d.unit === 'V'), d => d.value) || 1;

const xScaleK = d3.scaleLinear().domain([0, maxKohm * 1.2]).range([margin.left, width - margin.right - 200]);
const xScaleV = d3.scaleLinear().domain([0, maxVolt * 1.2]).range([margin.left, width - margin.right]);

const yScale = d3.scaleBand().domain(values.map(d => d.name)).range([margin.top, height - margin.bottom]).padding(0.2);

// Achsen
const g = svg.append('g');

// Widerstände-Balken (links)
g.selectAll('.barK')
	.data(values.filter(d => d.unit === 'kΩ'))
	.enter()
	.append('rect')
	.attr('class', 'barK')
	.attr('x', margin.left)
	.attr('y', d => yScale(d.name))
	.attr('height', yScale.bandwidth() / 2)
	.attr('width', d => xScaleK(d.value) - margin.left)
	.attr('fill', '#6baed6');

// Spannungen-Balken (rechts, überlagert halbtransparent)
g.selectAll('.barV')
	.data(values.filter(d => d.unit === 'V'))
	.enter()
	.append('rect')
	.attr('class', 'barV')
	.attr('x', margin.left)
	.attr('y', d => yScale(d.name) + yScale.bandwidth() / 2)
	.attr('height', yScale.bandwidth() / 2)
	.attr('width', d => xScaleV(d.value) - margin.left)
	.attr('fill', '#fd8d3c');

// Beschriftungen Werte
g.selectAll('.label')
	.data(values)
	.enter()
	.append('text')
	.attr('x', width - margin.right - 180)
	.attr('y', d => yScale(d.name) + yScale.bandwidth() / 2 + 6)
	.text(d => `${d.name}: ${Math.round(d.value * 1000) / 1000} ${d.unit}`)
	.attr('font-family', 'sans-serif')
	.attr('font-size', 12);

// Titel
svg.append('text')
	.attr('x', width / 2)
	.attr('y', 16)
	.attr('text-anchor', 'middle')
	.attr('font-family', 'sans-serif')
	.attr('font-size', 14)
	.text('Spannungsteiler: Widerstände (kΩ) und Spannungen (V)');

// SVG speichern
const svgString = body.select('svg').node().outerHTML;
fs.writeFileSync('divider_visualization.svg', svgString, 'utf8');
console.log('SVG: divider_visualization.svg erzeugt');
```

### Kurzresultate (numerisch)
- Unbelastete Spannung am 15 kΩ: 165 V.  
- Innenwiderstand Messgerät Rm: 10 kΩ.  
- Effektiver unterer Widerstand (15kΩ || 10kΩ): 6 kΩ.  
- Gemessene Spannung mit Belastung: 120 V.

### Hinweise
- Das Skript verwendet mathjs-Unit-Objekte für saubere Einheitenrechnung.  
- Die Visualisierung ist bewusst einfach (Balken + Text). Du kannst Farben, Skalierung oder Layout in den d3-Abschnitten leicht anpassen.
