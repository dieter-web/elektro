#### Knotenmatrix (vereinfachte Darstellung)
Da die beiden Parallelschaltungen in Reihe liegen, führt eine direkte Knotenanalyse mit zwei unabhängigen Knoten auf die folgenden Gleichungen für die Spannungen an den Parallelschaltungsanschlüssen relativ zur Referenz (U_node1 = Spannung über linkem Parallelschaltungsblock, U_node2 = Spannung über rechtem Parallelschaltungsblock). Die Quellenspannung treibt die Reihenschaltung von Rp1 und Rp2, es gilt U = U1 + U2. Wir schreiben die algebraische Form als Matrizenproblem für U1 und U2:

- Für den linken Block gilt der relationale Strom I = G_{p1} * U1.
- Für den rechten Block gilt der relationale Strom I = G_{p2} * U2.
- Reihenzusammenhang: U1 + U2 = U.

Die Matrixdarstellung ist
$$
\begin{pmatrix}
G_{p1} & 0\\[6pt]
1 & 1
\end{pmatrix}
\begin{pmatrix}
U_1\\[6pt]
U_2
\end{pmatrix}
=
\begin{pmatrix}
I\\[6pt]
U
\end{pmatrix}.
$$
Da $I$ unbekannt ist, eliminieren wir I durch die Reihenzusammenhänge: Aus $I = G_{p1} U_1$ und $I = G_{p2} U_2$ folgt $G_{p1} U_1 = G_{p2} U_2$ und $U_1 + U_2 = U$. Das liefert das 2×2-LGS:
$$
\begin{pmatrix}
G_{p1} & -G_{p2}\\[6pt]
1 & 1
\end{pmatrix}
\begin{pmatrix}
U_1\\[6pt]
U_2
\end{pmatrix}
=
\begin{pmatrix}
0\\[6pt]
U
\end{pmatrix}.
$$

Setzen wir die Zahlen ein:
$$
G_{p1}=0.083333,\quad G_{p2}=0.066666,\quad U=13.5.
$$

Die Matrixgleichung numerisch:
$$
\begin{pmatrix}
0.083333 & -0.066666\\[6pt]
1 & 1
\end{pmatrix}
\begin{pmatrix}
U_1\\[6pt]
U_2
\end{pmatrix}
=
\begin{pmatrix}
0\\[6pt]
13.5
\end{pmatrix}.
$$

Lösen mit linearer Algebra (Inverse oder Gauss):

Berechne Determinante:
$$
\Delta = 0.083333\cdot 1 - (-0.066666)\cdot 1 = 0.083333 + 0.066666 = 0.149999 \approx 0.15.
$$

Inverse anwenden oder Cramers Regel:
$$
U_1 = \frac{1}{\Delta}\begin{vmatrix}0 & -0.066666\\[4pt]13.5 & 1\end{vmatrix}
= \frac{0\cdot 1 - (-0.066666)\cdot 13.5}{0.15}
= \frac{0 + 0.899991}{0.15}
\approx 5.99994\ \mathrm{V}.

U_2 = \frac{1}{\Delta}\begin{vmatrix}0.083333 & 0\\[4pt]1 & 13.5\end{vmatrix}

### Verallgemeinerung für größere Netzwerke

Kurz: Baue die Knotengleichungen in Leitwertform G·V = I auf, löse das lineare System mit math.lusolve und berechne Zweigströme per Ibranch = Gbranch · (Va - Vb). Unten findest du ein klares Algorithmus‑Schema und eine Node.js-Implementierung mit math.js und Einheiten.

---

### Algorithmus (Schritt für Schritt)
1. Repräsentiere das Netz als Liste von Knoten und Zweigen. Jeder Zweig: {n1, n2, R} (n2 kann null/ground sein, R in ohm).  
2. Erzeuge Leitwerte Gbranch = 1/R für jeden Zweig (als Zahl in S).  
3. Baue die Knotengleichungsmatrix G (NxN für N Knoten ohne Ground):  
   - Für jeden Zweig zwischen i und j (i≠j): G[i,i] += Gbranch; G[j,j] += Gbranch; G[i,j] -= Gbranch; G[j,i] -= Gbranch.  
   - Für Zweig i–ground: G[i,i] += Gbranch.  
4. Erzeuge den Rechtsvektor I (N×1) aus Stromquellen (vereinheitlicht: Stromquelle + Richtung in Knoten) oder aus bekannten Spannungsquellen durch Modifikation des Systems (siehe Hinweise unten).  
5. Löse V = G^{-1}·I oder math.lusolve(G,I).  
6. Berechne Ströme in jedem Zweig: Ibranch = Gbranch * (V[n1] - V[n2]) (wenn n2 = ground, V[n2]=0).  
7. Optional: überprüfe KCL an jedem Knoten (Summe Ströme ≈ 0) und Energiekonsistenz.

---

### Wichtige Hinweise zu Quellen und Einheiten
- Spannungsquellen zwischen zwei Nicht-Ground-Knoten erfordern Modifikation (z. B. erweiterte Matrix mit Schleifenstromen oder Verwendung der Knoten-Zweig-Matrix-Methode). Für reine Widerstandsnetzwerke mit einer oder mehreren Spannungsquellen zum Ground genügt G·V=I.  
- Nutze math.unit für Anzeige und Konvertierung; rechnest intern mit Zahlen in SI (V, S, A).  
- Wähle einen Knoten als Ground und nummeriere die restlichen Knoten 0..N-1.

### Node.js + math.js Implementierung (generisch, Einheiten)
```js
// netzwerk-solver.js
const math = require('mathjs')

// Helper: Leitwert aus Widerstand (ohm) -> Siemens (number)
function G_from_R(R_ohm) {
  return math.unit(1, 'S').toNumber('S') / math.unit(R_ohm, 'ohm').toNumber('S') * math.unit(1, 'S').toNumber('S')
}
// Simpler numeric form:
function G_from_R_num(R_ohm) {
  return 1 / R_ohm
}

/*
 Netzbeschreibung:
 - nodes: array of node names, one node must be '0' for ground or you provide groundIndex
 - branches: [{n1: index, n2: index_or_null_for_ground, R: ohm, type?: 'R'|'V'|'I', value?: value}]
   For now we handle only resistors and independent current sources.
   For voltage sources not referenced to ground, use extended methods (not shown).
*/

// Beispiel: drei Knoten (0 ground, 1, 2)
const nodes = ['0', '1', '2'] // index 0 is ground
const groundIndex = 0

// Beispielzweige: ersetze durch dein großes Netz
const branches = [
  { n1: 1, n2: 0, R: 30 },        // R between node1 and ground
  { n1: 1, n2: 2, R: 20 },        // R between node1 and node2
  { n1: 2, n2: 0, R: 15 },        // R between node2 and ground
  // Optional current source into node1: +I entering node1 from ground
  // { n1: 1, n2: 0, type: 'I', value: math.unit(0.1, 'A') }
]

// Build G (size (N-1)x(N-1) excluding ground)
const N = nodes.length
const M = N - 1 // unknown node voltages count
let G = math.zeros(M, M)
let Ivec = math.zeros(M, 1) // currents injected into node (A), positive into node

// Process branches: resistors -> populate G; current sources -> populate Ivec
for (const br of branches) {
  if (br.type && br.type === 'I') {
    // current source: value is math.Unit or number (A), assumed from n2 -> n1 (entering n1)
    const I_A = (math.typeOf(br.value) === 'Unit') ? br.value.toNumber('A') : br.value
    if (br.n1 !== groundIndex) Ivec.set([br.n1 - 1, 0], Ivec.get([br.n1 - 1, 0]) + I_A)
    if (br.n2 !== groundIndex) Ivec.set([br.n2 - 1, 0], Ivec.get([br.n2 - 1, 0]) - I_A)
    continue
  }
  // resistor
  const R = br.R
  const Gbr = G_from_R_num(R)
  const a = br.n1
  const b = br.n2
  if (a !== groundIndex && b !== groundIndex) {
    // indices in matrix are nodeIndex-1 (since ground omitted)
    const ia = a - 1
    const ib = b - 1
    G.set([ia, ia], G.get([ia, ia]) + Gbr)
    G.set([ib, ib], G.get([ib, ib]) + Gbr)
    G.set([ia, ib], G.get([ia, ib]) - Gbr)
    G.set([ib, ia], G.get([ib, ia]) - Gbr)
  } else if (a !== groundIndex && b === groundIndex) {
    const ia = a - 1
    G.set([ia, ia], G.get([ia, ia]) + Gbr)
  } else if (a === groundIndex && b !== groundIndex) {
    const ib = b - 1
    G.set([ib, ib], G.get([ib, ib]) + Gbr)
  }
}

// Solve G * V = I
const Vsol = math.lusolve(G, Ivec) // returns (M x 1)
const voltages = Array(N).fill(0) // include ground
voltages[groundIndex] = 0
for (let i = 1; i < N; i++) voltages[i] = Vsol.get([i - 1, 0])

// Compute branch currents: I = (V[n1]-V[n2]) / R
function branchCurrent(br) {
  if (br.type === 'I') {
    return (math.typeOf(br.value) === 'Unit') ? br.value.toNumber('A') : br.value
  }
  const v1 = voltages[br.n1]
  const v2 = (br.n2 === groundIndex) ? 0 : voltages[br.n2]
  return (v1 - v2) / br.R
}

// Ausgabe
console.log('G matrix:')
console.log(G.toString())
console.log('I vector:')
console.log(Ivec.toString())
console.log('Knoten-Spannungen (V):')
for (let i = 0; i < N; i++) {
  console.log(` node ${i}: ${math.unit(voltages[i], 'V').toString()}`)
}
console.log('Zweigströme (A), pos = von n1 nach n2:')
for (const br of branches) {
  const I = branchCurrent(br)
  console.log(` branch ${JSON.stringify(br)} -> ${math.unit(I, 'A').toString()}`)
}
```

### Erweiterungen und Tricks für große Netze
- Für viele Spannungsquellen zwischen Nicht-Ground-Knoten nutze die erweiterte Knotenspannungsform (MNA, Modified Nodal Analysis). Das bedeutet Systemmatrix erweitern um zusätzliche Gleichungen und Variablen für Quellenströme.  
- Verwende sparse Matrizen (math.sparse) bei sehr großen Netzen zur Speicher- und Laufzeitersparnis.  
- Validierung: KCL an allen Knoten prüfen und Leistungsbilanz (Sum(Ubranch·Ibranch) = 0 für passive netze) nutzen.  
- Automatische Netz-Eingabe: Netlist-Format (Spice-ähnlich) parsen und in branches/nodes konvertieren.
