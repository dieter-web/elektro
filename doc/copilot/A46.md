```haskell
a46 u1 u2 u3 ri1 ri2 ri3 r4 r5 r6 =
   let alpha = ri1 / ri2
       beta  = (u2 - u1) / ri2
       p     = r5 / (ri3 + r6) + 1
       q     = 1 + alpha
       r     = beta - (u3 / (ri3 + r6))
       s     = (ri2 + r4) * alpha + r4

       i4    = i1 + i2
```

```js
 * @param {string} modulName - z.B. "A46", "Resistor", ...
 * @param {Array} felder - Array von Feldern mit .value
 */
export async function transform(modulName, felder) {
  // Werte aus den Feldern extrahieren
  const values = felder.map(f => f.value);

  // Argumentliste für stack exec
  const args = ['exec', 'elektro-exe', modulName, ...values.map(String)];

  try {
    const { stdout } = await execFileAsync('stack', args);
    return JSON.parse(stdout);
  } catch (err) {
    throw new Error(`Fehler beim Haskell-Aufruf (${modulName}): ${err.message}`);
  }
}
```

## Ablauf

1. Dein Node‑Modul ruft `transform('a46', meta.felder)` auf.
2. `haskell.mjs` startet `stack exec elektro-exe a46 …` mit den Werten aus `meta.felder`.
3. Dein Haskell‑Executable gibt JSON zurück.
4. `transform` parst das JSON und liefert es zurück.
5. Du kannst die Ergebnisse direkt in deinem Frontend weiterverwenden.

---

✨ Damit hast du eine saubere Trennung:
- **Haskell** rechnet und liefert JSON.
- **Node.js** kapselt den Aufruf über `transform`.
- **Deine Aufgabenmodule** (`A46.mjs`, `Resistor.mjs`, …) bleiben schlank und deklarativ.

Als nächsten Schritt könnte ich dir zeigen, wie du dein `Main.hs` so erweiterst, dass es **alle Module** (`A46`, `Resistor`, `Parallel`, …) über denselben Mechanismus auswählbar macht – dann brauchst du nur noch `transform('resistor', …)` oder `transform('parallel', …)` aufzurufen.

Der Fehler sagt dir eigentlich schon genau, was passiert: dein Node‑Code (`transform`) versucht `stdout` als JSON zu parsen – aber dein Haskell‑Executable hat **keine JSON‑Ausgabe geliefert**, sondern nur den Usage‑Text:

```
Usage: elektro-exe a46 u1 u2 u3 ri1 ri2 ri3 r4 r5 r6
```

Das ist kein gültiges JSON → `JSON.parse` bricht ab mit *Unexpected token 'U'*.

---

### 🔎 Ursachen
- Du hast `stack exec elektro-exe a46 …` ohne oder mit falschen Parametern aufgerufen.
- Dein `Main.hs` gibt im Fehlerfall nur einen Usage‑String aus, nicht JSON.
- Dein Node‑Wrapper erwartet aber **immer** JSON.

---

### ✅ Lösungsmöglichkeiten

#### 1. Stelle sicher, dass du alle Parameter übergibst
Für `a46` brauchst du **9 Zahlen**:
```
stack exec elektro-exe a46 10 5 8 3 5 4 6 7 8
```
Dann sollte dein Haskell‑Programm JSON ausgeben wie:
```json
{"i1":..., "i2":..., "i3":..., "i4":..., "i5":...}
```

#### 2. Gib auch im Fehlerfall JSON zurück
Passe dein `Main.hs` an, damit es **immer** JSON liefert:

```haskell
_ -> BL.putStrLn $ Aeson.encode (Aeson.object
        ["error" Aeson..= ("Usage: elektro-exe a46 u1 u2 u3 ri1 ri2 ri3 r4 r5 r6" :: String)])
```

So bekommst du im Node‑Code statt eines Parsing‑Fehlers ein JSON‑Objekt mit `"error": "Usage: …"`.

---

### 📝 Beispiel `Main.hs` für A46

```haskell
main :: IO ()
main = do
  args <- getArgs
  case args of
    [u1,u2,u3,ri1,ri2,ri3,r4,r5,r6] -> do
      let (i1,i2,i3,i4,i5) = A46.a46 (read u1) (read u2) (read u3)
                                    (read ri1) (read ri2) (read ri3)
                                    (read r4) (read r5) (read r6)
      BL.putStrLn $ Aeson.encode (Aeson.object
        ["i1" Aeson..= i1, "i2" Aeson..= i2, "i3" Aeson..= i3, "i4" Aeson..= i4, "i5" Aeson..= i5])
    _ -> BL.putStrLn $ Aeson.encode (Aeson.object
        ["error" Aeson..= ("Usage: elektro-exe a46 u1 u2 u3 ri1 ri2 ri3 r4 r5 r6" :: String)])
```

---

### 🚀 Ergebnis
- Mit korrekten Parametern bekommst du JSON mit den Strömen.
- Mit falschen Parametern bekommst du JSON mit einem `"error"`‑Feld.
- Dein Node‑Code (`transform`) kann **immer** `JSON.parse(stdout)` ausführen, ohne abzustürzen.
